## How to Appear on This List

Every person who gets a Pull Request accepted into the repository is added to this list. See
[CONTRIBUTING.md](.github/CONTRIBUTING.md) to learn how to contribute.

This file complements [AUTHORS.md](./AUTHORS.md): that file is the standing maintainer roster with
area-of-responsibility ownership; this one is the rolling record of every contribution. Being
listed here carries no copyright implication — commit history remains authoritative.
