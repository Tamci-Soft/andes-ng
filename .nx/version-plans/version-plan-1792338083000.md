Add AndesTreeNavigation, the shared keyboard model for hierarchical widgets: visible-node ordering that skips collapsed subtrees (from items or from a node source, so windowed trees work), the active node, controlled or uncontrolled expanded keys, the TreeView keys with RTL mirroring and typeahead across levels, roving-tabindex and active-descendant focus, and per-item aria-level, aria-posinset, aria-setsize and aria-expanded signals.
