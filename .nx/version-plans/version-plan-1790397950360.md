Default size is now 14px text with one row 32px high, matching AndesInput (sm 24px, lg 40px with 16px text).

AndesTextarea also gains a soft `countMax` limit that flags overflow without blocking input, a custom `countStrategy` for measuring the value (e.g. counting each emoji as one), a `countExceedFormatter` that trims typed input past the limit, a `countTemplate` for custom counter markup, and a `clearIcon` template for the clear button.

A focused textarea now shows a single indicator - its border in the focus colour plus a soft 2px ring, on any focus - instead of an outline drawn outside the border; the border also tints on hover, warning uses the deeper amber, read-only keeps the normal background, disabled greys out its text instead of fading, and the count is 12px/20px.

The clear button now has one design shared with the other fields - a small muted disc with the "x" knocked out, 1em across with a 24px hit area, centred on the first line at the same inset as AndesInput, shown while the field is hovered or focused (always on touch screens), a Tab stop of its own named by the new `clearLabel` input (default "Clear"); AndesTextarea also gains `(focused)` / `(blurred)` outputs carrying the native FocusEvent, and keeps the shared over-limit rule: past `countMax` the counter turns red and the textarea gets `aria-invalid="true"`, without blocking typing.
