Badge and Tag feature completeness, plus design polish.

- New named palette hues (red, orange, amber, yellow, lime, green, teal, cyan, blue, indigo, purple, magenta, pink), themed for light and dark and exported as `ANDES_PALETTE_COLORS` / `AndesPaletteColor`. Accepted by AndesTag, AndesBadge and AndesBadgeRibbon `color`, with the same auto-contrast text as an arbitrary CSS color. These names used to pass through as raw CSS named colors; they now resolve to the themed hues.
- AndesBadge: `count` also takes a string (shown as-is; a numeric string counts as a number) and `null`. A `dot` with a count of exactly 0 now hides unless `showZero` is set. A standalone badge with a `color` and no count renders a colored dot beside its `text`. Appearing/hiding badges zoom in and out and a changed count rolls into place, never on first render and never under `prefers-reduced-motion`.
- AndesTag: new `icon` input (TemplateRef, rendered before any `slot=icon` content); `processing` and `error` status aliases for `info` and `danger`; `andes-tag-enter` / `andes-tag-leave` host classes for Angular's `animate.enter` / `animate.leave`, and `hideOnClose` now fades the tag out (instantly under reduced motion).
- AndesCheckableTagGroup: options accept an `icon` template and a `className` for the tag host.
- Polish: the Badge indicator and its `offset` follow the inline-end corner under RTL; status dots use the same severity accents as Alert (warning in its `-hover` shade so it clears 3:1); the processing pulse holds still as a soft halo under reduced motion; the status text sits on a whole-pixel line box. Tag lands on a whole-pixel 22px height, outlined tags use a softer half-strength border and filled tags Alert's tinted wash and border (now also for palette and custom colors), the close button gets a larger hit area and centered glyph, unchecked checkable tags get a visible hover surface, and interactive tags lift instead of darken on hover in the dark theme.

AndesBadge and AndesTag motion is softer: badges grow in from 80% without overshoot, a changed count lifts in from just below, the processing ping pulses slowly and faintly, and tags enter and leave as a near-pure fade. Badge counts are 12px in both sizes, and tags set their 12px label on a 20px line with eased hover colours.

In the dark theme, success/warning/info Badge counts and Ribbons keep a deep fill with light text (at least 5.2:1) instead of a bright pill with dark text, the Ribbon fold shades towards the theme's dark colour instead of a fixed black, and `status="default"` and secondary dots share a neutral that clears 3:1 on the page in both themes.
