Add `AndesMentions`, a text field (multi-line or single-line, with the shared field sizes, variants, statuses and counter) that suggests values while you type after a trigger character such as `@` or `#`. The list opens at the caret, filters live by the text after the trigger, supports async `loading` and a `searched` output for server-side filtering, custom option templates, a `split` string inserted after a pick, `validateSearch`, and full keyboard support (arrows, Enter or Tab to pick, Escape to close) with focus staying in the field. The value is the plain text, so it works with forms and `andes-form-field`.
