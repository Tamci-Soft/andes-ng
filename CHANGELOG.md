## 0.1.0 (2026-10-18)

### 🚀 Features

- **primitives:** First release: AndesButtonPrimitive, Andes-owned button behavior (disabled state, anchor click prevention), owned by Andes and used by AndesButton. ([4e71f27c](https://github.com/andes-ng/andes/commit/4e71f27c))
- **primitives:** Add a shared overlay behavior primitive (`AndesOverlayPrimitive` plus trigger/content/close directives) that Dialog, Drawer/Sheet, Popover, Tooltip and Dropdown Menu build on: portal rendering, anchored/centered/edge positioning with collision handling, optional focus trap and focus restoration, independently toggleable Escape and click-outside dismissal, scroll lock, and z-index/scrim wired to the `--andes-z-index-*` and `--andes-color-overlay` tokens. Closing supports exit animations: the pane, its direct element children and any backdrop get a `data-andes-closing` attribute (exported as `ANDES_OVERLAY_CLOSING_ATTRIBUTE`) and stop receiving pointer events, and the overlay detaches once the animations that attribute starts have finished, at most 300ms later (`ANDES_OVERLAY_EXIT_TIMEOUT_MS`); without an exit animation, under reduced motion or without animation support the close stays synchronous. `isOpen()` turns false immediately, focus restoration (skipped if the user moved focus elsewhere on the page during the exit) and `closed` follow the detach, and re-opening during the exit cancels it on the same pane. ([552eb31a](https://github.com/andes-ng/andes/commit/552eb31a))
- **primitives:** Add AndesListNavigation, the shared roving-tabindex / aria-activedescendant list-navigation primitive (arrow keys in either orientation, Home/End, configurable wrap, typeahead, disabled-item skipping), plus the AndesListNavigationItem and AndesListNavigationKeys directives - wrapping Angular CDK's own ListKeyManager family. ([928f98a2](https://github.com/andes-ng/andes/commit/928f98a2))
- **primitives:** Anchored overlays gain a `crossSideFallback` positioning option (default `true`): turned off, an overlay that fits neither on its preferred side nor the opposite one stays on that axis and is shifted into view, instead of moving to one of the perpendicular sides. ([f738f898](https://github.com/andes-ng/andes/commit/f738f898))
- **primitives:** Add viewport primitives: `andesElementSize` and `andesContainerBreakpoint` (element and container-width signals on one shared, frame-coalesced `ResizeObserver`), `andesMediaQuery` with reduced-motion, dark and contrast helpers, and an `AndesBreakpoints` service with `active`, `up`, `down` and `between` signals. All are server-safe and clean up with their injector. ([cbeaf2dc](https://github.com/andes-ng/andes/commit/cbeaf2dc))
- **primitives:** Add AndesChoiceGroup and AndesChoiceItem, the shared single/multiple-selection primitive behind radio groups, segmented controls, tabs, toggle-button groups and listbox pickers - roving-tabindex arrow navigation with selection that follows focus or waits for Space/Enter, RTL, wrap, disabled items, and a configurable ARIA role mapping (radiogroup, tablist, toolbar/group, listbox). ([7381d9a9](https://github.com/andes-ng/andes/commit/7381d9a9))
- **primitives:** Add `AndesSelectionModel`, a signal-based single/multiple selection with a maximum, per-item locking, key-based identity, `{added, removed}` change reporting, shift-click ranges and the tri-state select-all summary, plus `AndesCheckedTree`, hierarchical checked and half-checked state with parent/child propagation (or none in strict mode) over thousands of nodes. ([9021c47f](https://github.com/andes-ng/andes/commit/9021c47f))
- **primitives:** Add the shared form-control base: a value accessor that updates a component's value signal and notifies Angular forms once per real change, never echoes form writes back, merges the `disabled` input with the form's disabled state, and exposes the bound control's validity as signals for reactive forms, template-driven forms and signal forms. ([dd702106](https://github.com/andes-ng/andes/commit/dd702106))
- **primitives:** Add AndesTreeNavigation, the shared keyboard model for hierarchical widgets: visible-node ordering that skips collapsed subtrees (from items or from a node source, so windowed trees work), the active node, controlled or uncontrolled expanded keys, the TreeView keys with RTL mirroring and typeahead across levels, roving-tabindex and active-descendant focus, and per-item aria-level, aria-posinset, aria-setsize and aria-expanded signals. ([2b8b5583](https://github.com/andes-ng/andes/commit/2b8b5583))
- **testing:** Add getAndesButtonByName test helper. ([73124d4d](https://github.com/andes-ng/andes/commit/73124d4d))
- **tokens:** Add the first semantic token catalogue: color, spacing, radius, typography, and accent/border tokens for outline/ghost variants. ([73124d4d](https://github.com/andes-ng/andes/commit/73124d4d))
- **tokens:** Expand the token catalogue with card, popover, muted, input and radius-scale tokens and add dark mode via [data-andes-theme='dark'], using original color values. ([d3da4950](https://github.com/andes-ng/andes/commit/d3da4950))
- **tokens:** Add --andes-color-ghost/-primary-ghost/-danger-ghost, fixed regardless of light/dark, for the ghost display mode on AndesButton. ([1de4ed22](https://github.com/andes-ng/andes/commit/1de4ed22))
- **tokens:** Add an elevation scale (`--andes-shadow-sm`/`-md`/`-lg`), `--andes-color-primary-subtle` for selected rows and date ranges, `--andes-color-{success,info}-solid` (with `-hover`/`-active`) as aliases of the success/info fills, and the shorter motion names `--andes-duration-fast`/`-base`/`-slow` and `--andes-ease-out`/`-in` as aliases of the `--andes-motion-*` tokens. Motion tokens settle at 120/150/200ms with a `cubic-bezier(0.2, 0, 0, 1)` ease-out and a `cubic-bezier(0.4, 0, 1, 1)` ease-in, and `--andes-focus-halo` is a single 2px ring so a focused field shows one indicator. `--andes-color-danger-text` is `#b91c1c` on light surfaces (5.9:1 on the muted surface), and `--andes-color-warning-foreground` deepens to `#451a03` (7:1 on the amber fill, 4.7:1 on hover). Both themes keep `-foreground` at 4.5:1 on their fills and `-text` at 4.5:1 on the page, card, popover and muted surfaces; the token tests assert the final values and ratios. ([287275ba](https://github.com/andes-ng/andes/commit/287275ba))
- **tokens:** Adopt Geist as the default typeface: add an optional `fonts.css` entry point that bundles Geist and Geist Mono, point `--andes-font-family` at Geist (system fonts as fallback) and add `--andes-font-family-mono`, a font-size / line-height scale (`xs` to `2xl`) and regular/semibold/bold weights. ([1a19ff0d](https://github.com/andes-ng/andes/commit/1a19ff0d))
- **tokens:** Fix text contrast in interactive states: dark-theme primary/danger hover and active backgrounds now darken (matching the light theme) instead of lightening, so white button text stays above 4.5:1 (it fell to 2.5-3.8:1), and the light-theme muted foreground is a shade darker (#5f6f86) so muted text reaches 4.5:1 on the muted surface too. Adds --andes-color-ghost-foreground, the fixed text color for content on the --andes-color-ghost fill, and sets `color-scheme: dark` in the dark theme so native controls (checkboxes, scrollbars, date inputs) render dark. Adds `--andes-color-{danger,success,warning,info}-text` for status-colored text on page/card/muted surfaces (>=4.5:1 in both themes), darkens the success/info fills one step so white text on them passes, and makes the dark theme's success/info hover/active darken like primary/danger. Adds control-scale tokens (`--andes-control-{height,padding-x,font-size,radius}-{sm,md,lg}`, 24/32/40px controls with 14px text), component text tokens, motion tokens (`--andes-motion-duration-*`, `--andes-motion-ease-*`) and `--andes-focus-halo`. ([d12f01ae](https://github.com/andes-ng/andes/commit/d12f01ae))
- **ui:** Add AndesButton, the first component: primary/secondary/danger/outline/ghost/link variants, sm/md/lg/icon sizes, pill shape, and a loading state. ([73124d4d](https://github.com/andes-ng/andes/commit/73124d4d))
- **ui:** Add icon-xs size, data-slot/data-variant/data-size attributes, and aria-label/aria-labelledby/aria-describedby/aria-invalid forwarding to the real button/anchor (never the non-interactive host). ([0c6934c6](https://github.com/andes-ng/andes/commit/0c6934c6))
- **ui:** Add htmlType (as 'type', defaulting to 'button' - never the native submit default), target (for href), and a real ghost display mode (transparent, tinted to the variant's own color - distinct from the existing ghost variant). ([1de4ed22](https://github.com/andes-ng/andes/commit/1de4ed22))
- **ui:** Add dashed variant, a customizable loadingIcon (TemplateRef, falls back to the default spinner), and auto-sizing for any projected SVG icon (1em, scales with each size class's font-size). ([d5ab3582](https://github.com/andes-ng/andes/commit/d5ab3582))
- **ui:** AndesButton default size is now 32px high with 14px text (xs 20px, sm 24px, lg 40px; icon-only squares match), and icon-only buttons size their icon to the control size. ([9293aabd](https://github.com/andes-ng/andes/commit/9293aabd))

  AndesButton adds a `filled` variant, a `color` input (primary, danger, success, warning, info) that tints the solid, outline, dashed, filled, ghost and link variants, a `danger` shorthand, `round` and `circle` shapes, and a `ripple` toggle. The new AndesButtonGroup joins adjacent buttons into one segmented control (horizontal or vertical) and passes its `size` to buttons that don't set their own.
  AndesButton motion is quieter: the press ripple is a 10% wash, the loading spinner turns once a second, and an invalid button shows only its danger focus outline (no extra halo).
