## 0.1.0 (2026-10-18)

### 🚀 Features

- Fix text contrast in interactive states: dark-theme primary/danger hover and active backgrounds now darken (matching the light theme) instead of lightening, so white button text stays above 4.5:1 (it fell to 2.5-3.8:1), and the light-theme muted foreground is a shade darker (#5f6f86) so muted text reaches 4.5:1 on the muted surface too. Adds --andes-color-ghost-foreground, the fixed text color for content on the --andes-color-ghost fill, and sets `color-scheme: dark` in the dark theme so native controls (checkboxes, scrollbars, date inputs) render dark. Adds `--andes-color-{danger,success,warning,info}-text` for status-colored text on page/card/muted surfaces (>=4.5:1 in both themes), darkens the success/info fills one step so white text on them passes, and makes the dark theme's success/info hover/active darken like primary/danger. Adds control-scale tokens (`--andes-control-{height,padding-x,font-size,radius}-{sm,md,lg}`, 24/32/40px controls with 14px text), component text tokens, motion tokens (`--andes-motion-duration-*`, `--andes-motion-ease-*`) and `--andes-focus-halo`. ([d12f01ae](https://github.com/andes-ng/andes/commit/d12f01ae))
- Adopt Geist as the default typeface: add an optional `fonts.css` entry point that bundles Geist and Geist Mono, point `--andes-font-family` at Geist (system fonts as fallback) and add `--andes-font-family-mono`, a font-size / line-height scale (`xs` to `2xl`) and regular/semibold/bold weights. ([1a19ff0d](https://github.com/andes-ng/andes/commit/1a19ff0d))
- Add an elevation scale (`--andes-shadow-sm`/`-md`/`-lg`), `--andes-color-primary-subtle` for selected rows and date ranges, `--andes-color-{success,info}-solid` (with `-hover`/`-active`) as aliases of the success/info fills, and the shorter motion names `--andes-duration-fast`/`-base`/`-slow` and `--andes-ease-out`/`-in` as aliases of the `--andes-motion-*` tokens. Motion tokens settle at 120/150/200ms with a `cubic-bezier(0.2, 0, 0, 1)` ease-out and a `cubic-bezier(0.4, 0, 1, 1)` ease-in, and `--andes-focus-halo` is a single 2px ring so a focused field shows one indicator. `--andes-color-danger-text` is `#b91c1c` on light surfaces (5.9:1 on the muted surface), and `--andes-color-warning-foreground` deepens to `#451a03` (7:1 on the amber fill, 4.7:1 on hover). Both themes keep `-foreground` at 4.5:1 on their fills and `-text` at 4.5:1 on the page, card, popover and muted surfaces; the token tests assert the final values and ratios. ([287275ba](https://github.com/andes-ng/andes/commit/287275ba))
- Add --andes-color-ghost/-primary-ghost/-danger-ghost, fixed regardless of light/dark, for the ghost display mode on AndesButton. ([1de4ed22](https://github.com/andes-ng/andes/commit/1de4ed22))
- Expand the token catalogue with card, popover, muted, input and radius-scale tokens and add dark mode via [data-andes-theme='dark'], using original color values. ([d3da4950](https://github.com/andes-ng/andes/commit/d3da4950))
- Add the first semantic token catalogue: color, spacing, radius, typography, and accent/border tokens for outline/ghost variants. ([73124d4d](https://github.com/andes-ng/andes/commit/73124d4d))
