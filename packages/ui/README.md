# @andes-ng/ui

Standalone, accessible Angular components for Andes NG.

```ts
import { AndesButton } from '@andes-ng/ui';
```

```html
<button andesButton type="button">Guardar</button>
```

Import `@andes-ng/tokens/theme.css` once in the consumer application's global stylesheet. Do not import Spartan Brain directly; it is an implementation detail and is not covered by the Andes public API compatibility guarantee.
